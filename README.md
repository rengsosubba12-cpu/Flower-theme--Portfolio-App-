# 🌸 Flower Theme Portfolio App

An aesthetic, cross-platform personal portfolio application built with **Flutter**, featuring a custom floral-inspired theme and smooth animations.

---

## ✨ Features

* **Floral Aesthetic Theme:** Custom-styled UI elements utilizing a soft, elegant flower-themed color palette and visual design.
* **Interactive Portfolio Layouts:** Clean showcase views for displaying professional experience, projects, and skills.
* **Cross-Platform:** Developed with Flutter to run seamlessly across mobile (Android, iOS) and web.

---

## 🛠️ Tech Stack

* **Framework:** [Flutter](https://flutter.dev) (Dart)
* **UI/UX:** Custom animations, responsive layouts, and specialized styling packages.

---
